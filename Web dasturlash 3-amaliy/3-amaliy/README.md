
# 3-amaliy ish — JavaScript asoslari

**Talaba:** Komilova Kamola Bahodir qizi

**Guruh:** 941-24

**Variant:** 7

## Amaliy ish haqida

Ushbu amaliy ishda JavaScript dasturlash tilida
5 ta masala bajarildi.

## Bajarilgan masalalar

| № | Funksiya nomi | Holati |
|---|---|---|
| 1 | haroratOgir(c) | Bajarildi |
| 2 | satrQisqartir(s, n) | Bajarildi |
| 3 | elementQidir(arr, x) | Bajarildi |
| 4 | sezarShifri(s, k) | Bajarildi |
| 5 | engUzunOsish(arr) | Bajarildi |

## Ishlatilgan texnologiyalar

- HTML
- JavaScript

## Dasturni ishga tushirish

1. index.html faylini brauzerda ochish.
2. F12 tugmasini bosish.
3. Console bo'limiga kirish.
4. Natijalarni ko'rish.

## Xulosa

Ushbu amaliy ish davomida JavaScript tilida
funksiyalar, massivlar, satrlar va sikllar bilan
ishlash ko'nikmalari mustahkamlandi.
